## Goed om te weten

- **Echte code uit echte projecten.** De voorbeelden komen uit klantprojecten van Webreact, zoals Vonders.nl, Niped.nl en TVK.nl. Ik deel ze met toestemming van Webreact.
- **Alleen mijn eigen werk.** Met `git log` en `git blame` heb ik gecontroleerd welke code van mij is. Waar een bestand deels van een collega is, staat dat erbij.
- **Ingekort waar nodig.** Stukken die niet bij het onderwerp horen, zijn weggelaten en gemarkeerd met `(ingekort)`. Bovenaan elk bestand staat uit welk project en pad het komt.
- **Geen gevoelige gegevens.** Sleutels, wachtwoorden, serveradressen en persoonsgegevens zijn verwijderd of vervangen door een placeholder.
- **Niet los te draaien.** Het zijn fragmenten uit grotere applicaties. Ze laten zien hoe ik code opbouw, niet een werkend project.
